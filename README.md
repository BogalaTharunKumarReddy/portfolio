```bash
npm install

npm run build      # type-check + production build into dist/

```

## Make it yours (all content lives in `src/data/`)

| File | What to edit |
| --- | --- |
| `profile.ts` | **LinkedIn URL and site URL** (search for `TODO(edit)`), name, headline, email |
| `about.ts` | About paragraphs, quick facts |
| `education.ts` | Add your Class XII / X details (placeholders are flagged on screen) |
| `experience.ts` | Replace the "Next" placeholder with your first internship or job |
| `skills.ts` | Only list what you can discuss in an interview |
| `projects.ts` | **Verify every `TODO(verify)`**: stacks, features and case studies are drafts. Add `links.github` / `links.live` and the buttons appear |
| `certificates.ts` | Real certificates are listed; add `url` (verification link) to show a Verify button; images in `public/certificates/` |
| `blog.ts` | Add posts as objects; they get a page at `/blog/<slug>` automatically |

### Assets
- **Your photo:** `public/profile.jpg` (square, 800 px, shown as a circle in About) and `public/profile-avatar.jpg` (tight face crop for the hero avatar). Replace both files to change it; paths are set in `src/data/profile.ts`. If a file is missing, a monogram is shown.
- **Resume PDF:** `public/resume.pdf` (a starter is generated by `python3 scripts/make_resume.py`; or drop in your own file with the same name).
- **Social preview image:** `python3 scripts/make_og_image.py`.
- **Domain:** replace `https://your-portfolio.vercel.app` in `index.html`, `public/robots.txt`, `public/sitemap.xml` and `SITE_URL` in `src/data/profile.ts`.

### Contact form
No backend is included. By default the form opens the visitor's email app (`mailto:`). To receive messages directly, create a free form at [Formspree](https://formspree.io) and set `VITE_CONTACT_ENDPOINT` (see `.env.example`). That value is public by design; never put private keys in `VITE_*` variables.

### GitHub section
Uses the public GitHub REST API with no token (60 requests/hour per visitor IP, cached for 10 minutes in `sessionStorage`). Change the username in `profile.githubUsername`.

## Features worth knowing about
- **Live demos:** each project page has an interactive demo (`src/components/demos/`) that runs on sample data in the browser. Add `links.live` in `projects.ts` to also show a "Deployed site" button.
- **Workspace:** an interactive 3D desk with day/night mode and a tools list (`src/components/workspace/ToolsPanel.tsx`).
- **Hero:** an animated 3D cartoon developer typing at a laptop (`src/components/three/DevScene.tsx`, textures in `devTextures.ts`). Panels show your real skills and projects; blinks, head follows the pointer. Falls back to `public/hero-developer.webp` without WebGL.
- **Back to top:** floating button appears after scrolling (`src/components/layout/BackToTop.tsx`).
- **Project images:** cover images live in `public/projects/<slug>.webp` (16:10) and are set with `image` in `src/data/projects.ts`; they are screenshots of the live demos. Auto-synced GitHub repos use GitHub's own repo preview image.
- **Auto-synced GitHub repos:** any new public, non-fork repo appears in the GitHub section ("More from GitHub") on the next page load, no redeploy needed. Repos already showcased, the profile README repo and names in `githubHiddenRepos` (`src/data/profile.ts`) are skipped. Uses the public GitHub API (no token, cached 10 min, 60 requests/hour per visitor IP).
- **Themes:** light by default with a dark toggle; palettes are CSS variables at the top of `src/index.css`.
- **Font:** Times New Roman everywhere (set in `tailwind.config.js`); code panels keep a monospace face.

## Deploy to Vercel
Import the repo in Vercel (framework preset: Vite). `vercel.json` already rewrites routes to `index.html` so `/projects/...` and `/blog/...` work on refresh.

## Performance, accessibility and motion
- 3D scenes are code-split and mount only near the viewport, pause offscreen, cap pixel ratio at 1.5 and fall back to a static visual without WebGL or on error.
- `prefers-reduced-motion` disables parallax, tilt, magnetic effects, particle motion, loops and reveal animations.
- Semantic landmarks, skip link, visible focus, focus-trapped menu and lightbox, labelled form fields with inline errors, `aria-current` navigation.
